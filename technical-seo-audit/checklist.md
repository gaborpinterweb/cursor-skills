# Checklist overview (15 areas)

The expandable **rules** live in [rules.md](rules.md) (69 atomic checks).  
These 15 areas are the taxonomy used in evidence and handoff mapping.

1. Titles & meta descriptions  
2. Crawlability & indexability  
3. Canonical URLs  
4. Mobile-first basics  
5. Performance / CWV readiness  
6. HTTPS / host  
7. Semantic HTML & headings  
8. Image SEO  
9. JSON-LD structured data  
10. Clean URL structure  
11. Internal linking  
12. Open Graph / Twitter cards  
13. Status codes & error UX  
14. International / hreflang  
15. Crawl-budget polish  

Plus attachment-driven **X-*** rules (SF Issues + PSI).

## SF blind spots (always verify in code)

- JSON-LD presence/quality  
- `Sitemap:` in robots.txt  
- Complete OG / `twitter:card`  
- CWV (needs PSI/Unlighthouse attachment)  
- Canonical host vs crawl URL  
- Orphans beyond “no anchor text”
